# Investment Analysis: NetApp (NTAP), Okta (OKTA), and FMCSX

A comprehensive equity and fund analysis project evaluating long-term investment potential using Bloomberg Terminal data, ratio analysis, and risk metrics.

---

## Project Overview

This 110-page analysis was completed as the capstone for my undergraduate Investment Analysis course. It includes deep dives into two large-cap companies (NetApp Inc. and Okta Inc.) and one mutual fund (Fidelity Mid-Cap Stock Fund - FMCSX), with the goal of constructing a portfolio aligned with a moderately aggressive investor profile.

---

## Tools & Data Sources

- Bloomberg Terminal: Financial statements, ratios, beta, analyst forecasts  
- Python (light use): Calculation checks, basic visual validation  
- Excel: Used extensively for ratio modeling, projection tables, and return tracking  
- Company 10-Ks, Morningstar, Yahoo Finance: Qualitative data and performance metrics

---

## Key Components

- Investor profile, risk tolerance, and required rate of return (CAPM: 11.14%)  
- Full company breakdowns: management, risks, industry peers, heat maps  
- Ratio analysis (profitability, liquidity, leverage, efficiency) over multiple years  
- Pro forma income statements and balance sheets  
- Sustainable growth rate and free cash flow projections  
- Insider transactions, short interest, options data, analyst recommendations  
- Final $30K portfolio beta and performance assessment

---

## Portfolio Snapshot

- Holdings: NetApp, Okta, FMCSX  
- Target Beta: ≤ 1.15  
- Actual Beta: ~1.04  
- Expected Return: > 11.14%  
- Holding Period: Tracked and assessed over 3 months

- How to perform real-world investment research using institutional tools like Bloomberg  
- How to evaluate companies through both quantitative and qualitative lenses  
- How to write, structure, and present a professional-grade investment thesis
